创建对象两种写法

最常用的是对象字面量，用大括号把一组组"键 : 值"装进去；也可以用 new Object() 再逐个添加属性。

var stu = {
  name: '小明', age: 10,
  hobby: '画画'
};
var dog = new Object();
dog.name = '旺财';
键 name值 '小明' 键值成对出现
点语法 / 方括号读取属性

点语法简单直观；方括号里可以放变量或带特殊字符的键名，更灵活。

stu.name → '小明'
stu['name'] → '小明'
var key = 'age';
stu[key] → 10（方括号可用变量）
stu.name stu['name'] stu[key] ✓
方法与 this对象的行为

属性值是函数时就叫方法，方法里用 this 指向当前这个对象自己，就像说"我"。

var stu = {
  name: '小明',
  sayHi: function () {
    return '我是' + this.name;
  }
};
stu.sayHi() → '我是小明'
this → stu 自己 谁调用，this 就指向谁
for...in 遍历逐个访问

用 for...in 循环把对象的每个键名挨个取出来，再用方括号取出对应的值。

for (var k in stu) {
  console.log(k, stu[k]);
}
// name 小明 / age 10 / hobby 画画
k = 'name' k = 'age' k = 'hobby'
Object.keys / values批量取键值

Object.keys 拿到全部键名组成的新数组，Object.values 拿到全部值。

Object.keys(stu)
→ ['name', 'age', 'hobby']
Object.values(stu)
→ ['小明', 10, '画画']
keys → 键名数组 values → 值数组
delete / 添加增删属性

对象随时可以添加新属性（直接赋值）、用 delete 删除已有属性。

stu.grade = '三班'; // 添加
stu['age'] = 11; // 修改
delete stu.hobby; // 删除
stu → { name:'小明', age:11, grade:'三班' }
＋ 添加 ↻ 修改 － delete 删除
内置对象 Math / Date现成能用

JavaScript 自带很多内置对象，Math 管数学计算，Date 管日期时间，不用创建直接调用。

Math.max(3, 9, 6) → 9
Math.round(4.6) → 5
var d = new Date();
d.getFullYear() → 2026
Math 随取随用 new Date() 创建日期对象
