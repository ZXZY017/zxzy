JSON：数据的“包裹盒”

JSON 是一种纯文本的数据交换格式，长得和 JavaScript 对象很像，但它本质上是一串字符串—— 就像把数据装进盒子里再快递出去，收到后用 JSON.parse() 拆包、发出前用 JSON.stringify() 打包。 它只支持 6 种数据类型：字符串、数字、布尔、null、对象、数组。

一、JS 对象 与 JSON 字符串 的区别

JavaScript 对象键值对 · 可操作
{ name: "张三", age: 16, isBoy: true } // 键可以不加引号，还能写注释
JSON 字符串文本 · 用于传输
{ "name": "张三", "age": 16, "isBoy": true } // 键必须加双引号，不能写注释

二、JSON 的四条硬性规则

① 键必须用双引号

单引号或无引号都会被拒绝。

{ name: "张三" } { 'name': "张三" } { "name": "张三" }

② 字符串只能用双引号

字符串值同样不能写成单引号。

"city": '北京' "city": "北京"

③ 末尾不能多一个逗号

最后一项后面不能再写逗号。

{ "a": 1, } { "a": 1 }

④ 不能出现注释、undefined、函数

JSON 只存数据，不存代码逻辑。

{ "fn": function(){} } { "score": 92 }
