异步包饺子

包饺子要一步一步来：先买原料，再取原料； 原料到手后，和面与和馅可以同时进行（用 Promise.all() 等待两件事都完成）； 然后包饺子，最后吃饺子。 每一步都用 setTimeout 模拟真实耗时（买原料 6 秒、取原料 2 秒、和面 5 秒、和馅 4 秒、包饺子 6 秒、吃饺子 2 秒）， 整个流程用 async / await 串起来，像写同步代码一样清楚。

一、开始做一顿饺子

已用时间 0.0 s
当前步骤：—　（总用时预计 21.0 秒）
🛒
1. 买原料 6 秒 等待中
面粉、猪肉、白菜、葱姜，一样都不能少
🧺
2. 取原料 2 秒 等待中
把买好的原料取回家，洗干净、摆上案板
Promise.all([ 和面, 和馅 ])　↓　同时开工
🥣
3. 和面 5 秒 等待中
面粉加水，揉成光滑的面团，醒一会儿
🥬
3. 和馅 4 秒 等待中
猪肉白菜剁碎，加调料顺着一个方向搅上劲
🥟
4. 包饺子 6 秒 等待中
擀皮、放馅、捏出花边，一个接一个
🍽️
5. 吃饺子 2 秒 等待中
下锅煮熟，捞出蘸醋，趁热开吃
// 点击“开始包饺子”，观察每个阶段的执行顺序

二、对应的代码

// 用 setTimeout 包成 Promise，模拟每一步要花的时间 function 等待(ms) { return new Promise(function (resolve) { setTimeout(resolve, ms); }); } // 各步骤的模拟耗时（毫秒） function 买原料() { return 等待(6000); } // 6 秒 function 取原料() { return 等待(2000); } // 2 秒 function 和面() { return 等待(5000); } // 5 秒 function 和馅() { return 等待(4000); } // 4 秒 function 包饺子() { return 等待(6000); } // 6 秒 function 吃饺子() { return 等待(2000); } // 2 秒 // async 函数里可以用 await，把异步写得像同步 async function 做一顿饺子() { await 买原料(); // 6 秒，等它完成才走下一步 await 取原料(); // 2 秒 // 和面、和馅互不依赖，交给 Promise.all 同时进行 await Promise.all([ 和面(), 和馅() ]); // 取较慢的 5 秒 await 包饺子(); // 6 秒 await 吃饺子(); // 2 秒 }
