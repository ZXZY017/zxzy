04对比：<img> 引用 SVG 文件

用 <img src="..."> 引用 cdn/lide/icons/ 下的 .svg 文件，简单但无法用 CSS 修改内部颜色（此处用 filter 染色）。

05SVG 图标原理与用法

SVG 是纯文本矢量标记，直接内联进 DOM 后即成为页面的一部分。

<svg class="zhou-icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"> <path d="M19 14c1.49-1.46 3-3.21 3-5.5A5.5 5.5 0 0 0 16.5 3c-1.76 0-3 .5-4.5 2-1.5-1.5-2.74-2-4.5-2A5.5 5.5 0 0 0 2 8.5c0 2.3 1.5 4.05 3 5.5l7 7Z"/> </svg> /* 尺寸与颜色全部由外部 CSS 控制 */ .zhou-icon { width: 32px; height: 32px; color: #244e47; }

SVG 图标的优缺点：矢量无损缩放、CSS 完全可控（颜色/描边/动画）、可用 JS 操作、利于SEO与无障碍；内联会增大 HTML 体积，可用 <symbol> + <use> 雪碧图复用。本地 SVG 文件：cdn/lucide/icons/
