二、更多方法（图解示例）

indexOf / includes返回新值

indexOf 查找元素的下标（找不到返回 -1）；includes 判断是否存在，返回 true / false。

var arr = ['🍎','🍌','🍇'];
arr.indexOf('🍇') → 2
arr.includes('🍌') → true
🍎 0🍌 1 🍇 2 ← 找到了
concat返回新数组

把两个数组拼接成一个新数组，就像把两排盒子接到一起，原来的两排都不变。

var a = ['🍎','🍌'], b = ['🍇','🍓'];
a.concat(b) → ['🍎','🍌','🍇','🍓']
🍎🍌 ＋ 🍇🍓
map返回新数组

对每个元素逐一加工，得到一个长度相同的新数组，就像流水线给每个水果贴价签。

var arr = [1, 2, 3];
arr.map(function (x) { return x * 10; })
→ [10, 20, 30]
1 →10 2 →20 3 →30
filter返回新数组

按条件筛选，只留下满足条件的元素，就像用筛子把大水果留下来。

var arr = [5, 12, 8, 20, 3];
arr.filter(function (x) { return x > 6; })
→ [12, 8, 20]
5 ✕12 ✓ 8 ✓20 ✓ 3 ✕
find / findIndex返回新值

find 返回第一个满足条件的元素（找不到返回 undefined）；findIndex 返回它的下标。

var arr = [3, 9, 15, 22];
arr.find(function (x) { return x > 10; })
→ 15（第一个大于 10 的）
39 15 ← 第一个22
reduce返回新值

把所有元素累积汇总成一个值，就像把整排水果逐个装进同一个篮子里。

var arr = [1, 2, 3, 4];
arr.reduce(function (sum, x) { return sum + x; })
→ 10（1+2+3+4）
1＋ 2＋ 3＋ 4＝ 10
forEach无返回值

对每个元素执行一次操作，不产生新数组，就像挨个检查每个盒子。

var arr = ['🍎','🍌','🍇'];
arr.forEach(function (x, i) {
  console.log(i, x); // 0 🍎 / 1 🍌 / 2 🍇
});
→ 🍎→ 🍌→ 🍇
Array.isArray返回新值

判断一个变量是不是数组，比 typeof 更准确（typeof 数组会返回 "object"）。

Array.isArray(['🍎']) → true
Array.isArray('🍎') → false
['🍎'] 是数组 ✓ '🍎' 不是数组 ✕
