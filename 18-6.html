用文本画图：智能客服系统

Mermaid 是一种用文本描述图形的工具：把 flowchart / erDiagram 写进页面，脚本会自动渲染成 SVG。本页引入本地文件 cdn/mermaid/mermaid.min.js（已下载，离线可用）， 上图为系统流程图，下图为会话数据的 ER 图。

一、智能客服系统流程图

从用户提问到人工兜底的完整链路

用 flowchart TD 描述自上而下的流程：圆角节点是开始 / 结束，菱形是判断，普通矩形是处理步骤，虚线表示数据回流。

flowchart TD 
flowchart TD
    A(["用户提问"]) --> B["接入网关<br/>鉴权 · 限流 · 路由"]
    B --> C["意图识别<br/>文本分类 + 槽位抽取"]
    C --> D{"意图与槽位<br/>是否明确?"}
    D -- 否 --> E["多轮澄清<br/>追问缺失信息"]
    E --> C
    D -- 是 --> F["知识检索<br/>向量检索 + BM25 + 重排"]
    F --> G["LLM 生成答案<br/>Prompt 注入知识片段"]
    G --> H{"置信度<br/>≥ 阈值?"}
    H -- 是 --> I(["返回答案<br/>附引用来源"])
    H -- 否 --> J["转人工坐席<br/>携带会话上下文"]
    I --> K["会话记录<br/>质检与标注"]
    J --> K
    K -. 数据回流 .-> L["知识库与模型迭代"]
    L -.-> F

读图顺序：用户提问 → 网关校验 → 意图识别；若信息不足则多轮澄清后重新识别； 信息完整就进入 RAG 检索（向量 + BM25 + 重排）并由大模型生成答案； 置信度达标直接回复，否则转人工；无论哪条路径，会话都会进入记录与标注， 通过虚线回流到知识库与模型，形成持续迭代的闭环。

二、会话数据 ER 图

用户 / 会话 / 消息 / 知识的关系模型

用 erDiagram 描述实体、属性与关系：||--o{ 表示一对多，}o--o{ 表示多对多，每个实体大括号里写字段类型、主外键与注释。

erDiagram 
erDiagram
    USER ||--o{ SESSION : "发起"
    SESSION ||--o{ MESSAGE : "包含"
    MESSAGE }o--o| INTENT : "识别为"
    INTENT ||--o{ ANSWER : "生成"
    ANSWER }o--o{ KNOWLEDGE : "引用"
    KNOWLEDGE }o--|| CATEGORY : "归属"
    AGENT |o--o{ SESSION : "接管"

    USER {
        bigint id PK "用户ID"
        varchar nickname "昵称"
        varchar phone "手机号"
    }
    SESSION {
        bigint id PK "会话ID"
        bigint user_id FK "所属用户"
        varchar channel "网页/微信/电话"
    }
    MESSAGE {
        bigint id PK "消息ID"
        bigint session_id FK "所属会话"
        text content "消息内容"
    }
    INTENT {
        bigint id PK "意图ID"
        bigint message_id FK "来源消息"
        decimal confidence "置信度"
    }
    ANSWER {
        bigint id PK "答案ID"
        bigint intent_id FK "对应意图"
        text content "回答内容"
    }
    KNOWLEDGE {
        bigint id PK "知识ID"
        bigint category_id FK "所属分类"
        varchar title "标题"
    }
    CATEGORY {
        bigint id PK "分类ID"
        varchar name "分类名称"
    }
    AGENT {
        bigint id PK "坐席ID"
        varchar name "姓名"
        varchar status "在线/忙碌"
    }
关系说明：一个用户可以有多个会话，一个会话包含多条消息； 每条消息识别出一个意图，意图生成对应答案； 答案可以引用多条知识，知识归属分类；坐席可以接管会话。 这套模型能支撑多轮对话、知识溯源与人工协同。

三、Mermaid 语法要点

流程图方向与节点

flowchart TD 自上而下，LR 从左到右；
A["矩形"] 处理、B(["圆角"]) 起止、
C{"菱形"} 判断。

连线与文字

A --> B 实线箭头，A -.-> B 虚线箭头；
箭头中间加文字：D -- 否 --> E。

ER 图的基数符号

||--o{ 一对多，}|--|| 多对一，
}o--o{ 多对多，左端是起点实体的基数。

本地引入与初始化

引入 cdn/mermaid/mermaid.min.js 后，
调用 mermaid.initialize({...}) 设置主题，
再 mermaid.run() 渲染所有 .mermaid 元素。

说明：Mermaid 版本 11.4.1，文件保存在 cdn/mermaid/mermaid.min.js； 页面使用 default 主题并按站点配色微调字体；两个图均由文本实时渲染为 SVG，无需图片。
