JavaScript 程序结构 · 条件与循环

程序有三种基本控制结构：顺序、条件（分支）和循环。本页通过两个小例子演示if / else if / else 条件结构和 for、while 两种循环结构的用法。

条件结构：if / else if / else

输入一个 0 ~ 100 的分数，程序从上往下依次判断条件，命中哪个分支就执行哪段代码：

if (zxzy_score >= 90)      { zxzy_level = "优秀"; }
else if (zxzy_score >= 80) { zxzy_level = "良好"; }
else if (zxzy_score >= 60) { zxzy_level = "及格"; }
else                       { zxzy_level = "不及格"; }

循环结构：for 与 while

用 for 循环的嵌套打印九九乘法表，外层循环控制行，内层循环控制每行的列：

for (var zxzy_i = 1; zxzy_i <= 9; zxzy_i++) {
    for (var zxzy_j = 1; zxzy_j <= zxzy_i; zxzy_j++) {
        // 每次内层循环生成一个算式 zxzy_j × zxzy_i
    }
}

用 while 循环把 1 ~ 100 逐个累加，先执行条件判断，条件成立就一直循环：

while (zxzy_i <= 100) {
    zxzy_total = zxzy_total + zxzy_i;
    zxzy_i = zxzy_i + 1;
}
