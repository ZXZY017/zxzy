06列表图标（fa-ul / fa-li）

配合 ul.fa-ul 与 i.fa-li 自动对齐项目符号。

  • 字体图标即字符，颜色继承 color
  • 大小由 font-size 决定
  • 本地文件：cdn/fontawesome/css/all.min.css
  • 字体文件：cdn/fontawesome/webfonts/

07字体图标原理与用法

引入 CSS 后，图标本质上是「特殊字体里的字符」，由 ::before 的 content 码点渲染。

<link rel="stylesheet" href="cdn/fontawesome/css/all.min.css"> <i class="fa-solid fa-heart fa-2x"></i> <!-- 渲染为红色爱心 --> CSS 等价于： .fa-heart::before { content: "\f004"; } /* Unicode 私有区码点 */ @font-face { font-family: "Font Awesome 6 Free"; src: url("../webfonts/fa-solid-900.woff2") format("woff2"); }

字体图标的优缺点：矢量无限缩放、可用 CSS 控制颜色/阴影/动画、一次加载全站可用；但单色（duotone 除外）、依赖字体文件加载、语义需自行补 aria-label。
