JavaScript 基本数据类型

JavaScript 共有 6 种基本数据类型：String（字符串型）、Number（数值型）、Boolean（布尔型）、Undefined（未定义）、Null（空型）和 Object（对象型）。其中前 5 种为简单数据类型，Object 为引用数据类型。使用 typeof 运算符可以检测变量所属的数据类型，下面每种类型的示例变量都以 zxzy_ 前缀命名。

六种数据类型一览

字符串型 String

typeof → "string" 
var zxzy_str = "周徐倬玚";

实际值: "周徐倬玚"

用于表示文本数据，值需要使用单引号或双引号包裹。

数值型 Number

typeof → "number" 
var zxzy_num = 2026;

实际值: 2026

用于表示整数或浮点数，特殊值还有 NaN（非数值）和 Infinity（无穷大）。

布尔型 Boolean

typeof → "boolean" 
var zxzy_bool = true;

实际值: true

只有 true 和 false 两个值，常用于逻辑判断和条件控制。

未定义型 Undefined

typeof → "undefined" 
var zxzy_undef;  // 声明后未赋值

实际值: undefined

变量声明后未赋值时的默认值，表示"未定义"。

空型 Null

typeof → "object" 
var zxzy_null = null;

实际值: null

表示"空值"，可以主动赋值给变量。注意：typeof 检测 null 返回 object，这是 JavaScript 的历史遗留问题。

对象型 Object

typeof → "object" 
var zxzy_obj = { zxzy_name: "周徐倬玚", zxzy_course: "高级网页设计" };

实际值: zxzy_obj.zxzy_name = 周徐倬玚

引用数据类型，由键值对组成，用于描述复杂的数据结构。
